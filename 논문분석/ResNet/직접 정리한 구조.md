# ResNet-50 전체 구조

---

## BottleneckBlock 클래스 (nn.Module 상속)

### `__init__` 에서 레이어 정의

```
conv1    → 1×1 conv, 채널 압축 (256→64), 공간 유지
bn1      → 정규화
conv2    → 3×3 conv, 채널 유지 (64→64), 특징 추출
bn2      → 정규화
conv3    → 1×1 conv, 채널 복원 (64→256), 공간 유지
bn3      → 정규화
relu     → 비선형성 추가
shortcut → 채널/크기 다를 때만 1×1 conv로 맞춰줌
           같으면 nn.Sequential() (그냥 통과)
```

### `forward` 에서 실제 흐름

```
x → conv1 → bn1 → relu       (압축)
  → conv2 → bn2 → relu       (특징 추출)
  → conv3 → bn3              (복원, relu 아직 안 함)
  → out + shortcut(identity)  (F(x) + x, 잔차 연결)
  → relu                      (더한 후 비선형)
  → return
```

## ResNet50 클래스 (nn.Module 상속)

### `__init__` 에서 레이어 정의

```
Stem:
  conv1   → 7×7 conv, stride=2 (224→112, 3→64ch)
  bn1     → 정규화
  relu    → 비선형성
  maxpool → stride=2 (112→56)

Layer1~4: _make_layer로 병목블록 이어붙임
  layer1 → 블록 3개, stride=1, 56×56 유지,  64→256ch
  layer2 → 블록 4개, stride=2, 56→28×28,   256→512ch
  layer3 → 블록 6개, stride=2, 28→14×14,   512→1024ch
  layer4 → 블록 3개, stride=2, 14→7×7,     1024→2048ch

Head:
  avgpool → 7×7을 1×1로 압축 (채널별 평균, 2048 유지)
  flatten → (2048,1,1) → (2048,) 1차원으로 펼침
  fc      → 2048 → 101 (Food-101 클래스 수)
```

### `_make_layer`

```
첫 번째 블록: stride 적용 (크기/채널 변경 담당)
나머지 블록: for문으로 append (크기 유지, 특징 추출)
nn.Sequential(*layers)로 순서대로 연결해서 반환
```

### `forward` 에서 실제 흐름

```
x → stem (conv1→bn1→relu→maxpool)
  → layer1 → layer2 → layer3 → layer4
  → avgpool (2048,7,7) → (2048,1,1)
  → flatten (2048,1,1) → (2048,)
  → fc (2048,) → (101,)
  → return  ← 101개 클래스 점수
```
