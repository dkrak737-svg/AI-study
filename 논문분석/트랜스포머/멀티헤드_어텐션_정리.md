# 멀티헤드 어텐션 — 전체 흐름 정리

## 1. 입력 임베딩

4단어 → 임베딩 `[x, x, x, ..., x]` 형태의 **64차원 벡터 × 4** → **"입력 임베딩"**

---

## 한 헤드에서 일어나는 어텐션

> 논문에선 헤드 8개를 사용. 차원을 8(헤드 개수)로 나누면 됨.
> → 64차원을 8개로 나누면 **한 헤드당 8차원씩 할당**

### 2. Q, K, V 생성

멀티헤드 어텐션에 **(4, 64)** 로 들어가서
각각 다른 값의 가중치 행렬 3개 **(64, 8)** 를 만나
**(4, 8)짜리 Q, K, V** 가 만들어진다.

### 3. Q @ K.T — 관계 점수 계산

입력이 되는 Q와 K.T(전치)를 행렬곱하여 
각 q와 k의 내적을 계산하여 **총 16개의 내적** 이 나온다.

```
         K_1     K_2     K_3     K_4
Q_1  [Q1·K1  Q1·K2  Q1·K3  Q1·K4]    ← Q_1이 모든 K를 둘러봄
Q_2  [Q2·K1  Q2·K2  Q2·K3  Q2·K4]
Q_3  [Q3·K1  Q3·K2  Q3·K3  Q3·K4]
Q_4  [Q4·K1  Q4·K2  Q4·K3  Q4·K4]
```

각 Q가 어떤 K에 집중할지 내적을 통해 결정됨.
**Q가 집중하는 주체, K는 수동적인 역할.**

### 4. 스케일링

내적의 값이 너무 커지는 걸 막기 위해 **√d_k** 로 나눔.
(여기서 d_k = 8이므로 √8 ≈ 2.83으로 나눔)
→ 스케일링 → **"어텐션 스코어 출력"**

### 5. Softmax

각 행별로 softmax를 통과하여 **합이 1인 확률** 로 전환.
즉, 각 Q가 바라보는 K에 대한 확률 출력 (1, 4 모양 4개)
→ 이 값을 **"어텐션 가중치"** 라고 부름

### 6. V와 가중합

이렇게 만들어진 어텐션 가중치 **(4, 4)** 와 2번에서 만들어뒀던 V **(4, 8)** 를 
행렬곱(@)하여 **(4, 8)짜리 "헤드 출력" / "어텐션 출력"** 이 만들어짐.

→ **"4개 단어의 문맥을 반영한 새로운 표현"** (한 헤드의 관점으로)

- **입력**: 단어 하나하나의 고유 의미
- **출력**: 주변 단어 정보가 스며든 문맥 반영 표현

---

> 여기까지가 **"한 헤드"의 과정**. 총 8번 반복됨 (헤드 8개)

---

## 7. 헤드 결과 통합

**① Concatenate (이어붙이기)**

8개 헤드 각각의 출력 **(4, 8)** 을 가로로 이어붙임.
→ (4, 8) × 8개 이어붙이기 → **(4, 64)**

여기까지는 그냥 이어져 있는 상태. **이 정보를 섞어줘야 함.**

**② W_O로 섞기**

이어붙여진 결과에 마지막 가중치 **W_O (64, 64)** 를 행렬곱.
(학습을 통해 어떻게 섞는 게 좋을지 결정됨)

→ (4, 64) @ (64, 64) = **(4, 64)**

→ **"멀티헤드 어텐션의 최종 출력"**

---

## 핵심 shape 흐름 요약

```
입력 X             : (4, 64)
    ↓ × W_Q, W_K, W_V (64, 8)
Q, K, V            : (4, 8) 각각
    ↓ Q @ K.T
어텐션 스코어       : (4, 4)
    ↓ /√d_k, softmax
어텐션 가중치       : (4, 4)
    ↓ @ V
헤드 출력           : (4, 8)
    ↓ 8개 헤드 concat
이어붙인 결과        : (4, 64)
    ↓ @ W_O
최종 출력           : (4, 64)   ← 입력과 같은 형태로 복귀
```
