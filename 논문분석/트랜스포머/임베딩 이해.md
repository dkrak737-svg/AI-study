NLP — 임베딩과 학습 원리 (v2, 포지셔널 인코딩 추가)
1. 임베딩 (Embedding)
단어를 벡터로 표현한다.
단어 = [0.2, 0.5, -0.85, 0.3, ...]
이 벡터는 고차원 공간에서의 좌표(주소) 이며,
각 숫자는 각 축 방향의 성분이다 [↗, →, ↙, ↑].
벡터 전체가 방향과 길이를 동시에 나타낸다.
즉, 숫자들이 함께 하나의 방향과 길이를 만든다.

2. 의미 유사도 측정 — 내적

두 벡터의 내적이 크면 같은 방향 → 의미가 비슷하다.
내적이 0에 가까우면 → 무관.
내적이 음수면 → 반대 의미.


3. 행렬은 벡터를 변환하는 함수
벡터에 행렬을 곱하면 벡터의 위치(방향 + 길이 + 차원) 가 바뀐다.
행렬이 할 수 있는 일 (선형 변환)

회전: 방향 바꾸기
크기 조정: 길이 바꾸기
반사: 특정 평면 기준 뒤집기
전단: 공간 기울이기 (정사각형 → 마름모)
투영: 차원 압축 (일부 차원을 0으로)
차원 변경: 확장 또는 축소

→ 실제로는 이 변환들이 섞여서 일어난다.
행렬이 할 수 없는 일 (비선형 변환)

공간 구부리기
원점 이동 (편향 b로 따로 처리)
복잡한 경계 그리기

→ 이는 활성화 함수(ReLU, sigmoid 등)가 담당한다.

4. 학습의 본질 — 좋은 변환을 찾기
처음에 행렬 W는 랜덤이라 벡터를 엉뚱한 곳으로 보낸다.
학습이 진행되며 W가 조금씩 수정되어 결국:

"강아지"와 "고양이" 벡터 → 비슷한 방향
"강아지"와 "자동차" 벡터 → 다른 방향

공간을 의미 있게 재배치하는 변환을 찾아낸다.

학습 = 벡터들을 의미 있게 배치해주는 변환 행렬을 찾는 과정


5. 직교 벡터 — 완전히 독립된 방향

직교 벡터 = 내적이 0 = 방향이 완전히 독립
고차원에서는 서로 직교하는 방향이 매우 많이 존재한다.
무작위로 뽑은 고차원 벡터들은 자연스럽게 거의 직교한다.
이 성질 덕분에 고차원 임베딩 공간에 수많은 의미를 서로 간섭 없이 담을 수 있다.
멀티헤드 어텐션이 여러 관점을 동시에 보는 것도 이 원리의 응용.


6. 포지셔널 인코딩 (Positional Encoding)
왜 필요한가 — 어텐션은 순서를 모른다
어텐션은 단어 쌍의 내적으로만 관련성을 계산한다.
그래서 단어 순서가 바뀌어도 결과가 같다.

"개가 사람을 물었다"
"사람이 개를 물었다"

이 두 문장을 어텐션은 구분하지 못한다.
→ 위치 정보를 따로 주입해야 함.
해결 방법 — 임베딩에 위치 벡터를 더한다
최종 입력 = 단어 임베딩 + 포지셔널 인코딩
각 단어(1, 64)에 자기 자리에 해당하는 고유한 64차원 위치 벡터를 더함.
"점심" (1번째 자리): 단어 임베딩(1, 64) + 1번 자리 위치 벡터(1, 64) = (1, 64)
"메뉴" (2번째 자리): 단어 임베딩(1, 64) + 2번 자리 위치 벡터(1, 64) = (1, 64)
"추천" (3번째 자리): 단어 임베딩(1, 64) + 3번 자리 위치 벡터(1, 64) = (1, 64)
"좀"   (4번째 자리): 단어 임베딩(1, 64) + 4번 자리 위치 벡터(1, 64) = (1, 64)

자리마다 위치 벡터가 다름 → 각 위치를 구분 가능
차원이 늘어나지 않음 (64 + 64 = 64, 원소별 덧셈이라 shape 유지)
결과적으로 "같은 단어라도 자리가 다르면 다른 벡터"가 됨

위치 벡터를 만드는 방법
① 사인/코사인 함수 (원본 Transformer)
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

각 위치마다 고유한 패턴 생성
학습 없이 공식으로 계산 가능
훈련에 없던 긴 문장에도 바로 적용 가능

② 학습 가능한 포지셔널 임베딩 (BERT, GPT 등)

단어 임베딩처럼 랜덤 초기화 후 학습으로 값을 찾음
단순하고 성능도 잘 나와서 많이 쓰임

"더하면 정보가 섞이지 않나?" — 고차원 직교성 덕분
저차원(2D, 3D)에서는 더하면 정보가 엉킨다.
하지만 고차원에서는 단어 정보와 위치 정보가 서로 거의 직교하는 방향을 차지한다.

두 정보가 같은 벡터 안에 공존하지만
서로 간섭하지 않음
어텐션의 W_Q, W_K, W_V가 학습으로 필요한 정보만 뽑아내는 방법을 찾아냄

비유: 공기 중에 여러 라디오 방송이 동시에 존재하지만, 주파수만 맞추면 원하는 방송만 들을 수 있음.
최근 동향 — RoPE
최신 LLM(LLaMA 등)은 단순 더하기 대신 회전 변환으로 위치를 주입하는 RoPE(Rotary Position Embedding)를 많이 씀.
더하기의 잠재적 손상 없이 위치를 표현할 수 있어 더 깔끔함.

핵심 흐름 한 줄 정리

단어 → 벡터(임베딩) → 포지셔널 인코딩 더하기 → 내적으로 유사도 측정 → 행렬곱으로 변환 → 학습으로 좋은 변환 행렬을 찾음 → 고차원이라 수많은 의미를 직교하게 담을 수 있음
